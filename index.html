Some trails have come from the USGS, NPS, and other trail mapping volunteer groups. Hope to hear you on the air at a park. 🍻 es 73 - de N9FZ

Update - July 2026 🎇

What's new: The search bar has been greatly improved! It now searches summits and will look for text anywhere in the park/summit title or reference identifier.

"Community" maps have been added to some states: CA,IL,IN,MI,MN,NE,NM,NY. There may be existing overlap with the default PAD-US data but it does add some boundaries for parks that didn't have boundary data. A big thanks to Marty N9EAT for these! 🎉

A trail file has been added for US-3424 - Ice Age Floods National Geologic Trail. And the park update tool has been ran to update the POTA park list.

Update - April 2026 🌺

Added the "FFMA" layer to show all 488 Maidenhead 4 digit gridsquares of the CONUS. This is available for all states but is not selected by default. Useful for things like VUCC and FFMA or general gridsquare hunting.

I've also tweaked the UI to be more user friendly and added a link to the wiki

The park update tool has been ran to add any new POTA parks. 73 de N9FZ

Parks Update 2025-Dec

Ran the park update tool to pull in the new markers and remove any inactive parks. Rest-in-peace the old Virginia WMAs and State Fishing lakes. But Welcome to the new parks added in Nov and Dec. 73 de N9FZ

Update 2025-Nov: Added counties to all states.

The counties are hidden by default. Please select the counties in the layer switcher on the right-hand side. Only AK and RI don't have county shapes. Thanks to Marty N9EAT for the AK and RI county files. Also removed inactive summits that were included erroneously. 73 de N9FZ

Update 2025-Aug: Added summit markers from the SOTA program.

The summits are hidden by default. Please select the Summits in the layer switcher on the right-hand side and zoom in. They won't show up if you're zoomed out too far. 73 de N9FZ
